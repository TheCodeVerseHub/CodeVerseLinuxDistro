# Roadmap

This project is still evolving. These are practical next steps (subject to change).

## Near term

- Stabilize `cvh-install` flows (disk selection, error handling, defaults)
- Document supported hardware/VM expectations
- Tighten ISO build reproducibility (documented versions, known-good deps)

## Mid term

- CI to lint shell scripts and validate ISO profile structure
- Expand compositor profiles (niri/Hyprland) and keep configs consistent
- Signed packages / repository metadata improvements

## Long term

- Friendlier installer UX and recovery options
- Hardware enablement & driver guidance
- Release process (versioning, changelog, release artifacts)
