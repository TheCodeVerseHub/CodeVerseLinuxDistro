# Configuration Files Guide

This document explains the purpose of configuration files in the `configs/` folder.

## 1. Niri
Niri is a Wayland compositor. Its config file controls window layout and behavior.

## 2. Waybar
Waybar is a customizable status bar. It shows system info like time, battery, and network.

## 3. Rofi
Rofi is an application launcher. It helps in quickly opening apps and switching windows.

---

These config files help customize the Linux desktop experience.
